# Vendored frontend dependencies

These files are included to avoid runtime CDN dependencies. Copyright/license
headers are retained in each distributed file. Full license texts are included
alongside them under `static/vendor/`. Source-map pointers are removed because
the upstream source maps are not shipped.

| Asset | Version | Source | License |
| --- | --- | --- | --- |
| Bootstrap CSS | 5.3.8 | https://github.com/twbs/bootstrap | MIT |
| HTMX | 2.0.8 | https://github.com/bigskysoftware/htmx | BSD 2-Clause |
| Chart.js | 4.5.1 | https://github.com/chartjs/Chart.js | MIT |

Vehicle photos load directly from source-advert image URLs and are not bundled
or redistributed in this repository. Synthetic test fixtures contain no copied
seller descriptions or real seller contact details.
